# Bazaar Admin Dashboard

A standalone multi-page admin console for an India-focused multivendor marketplace. Built with HTML5, CSS3, vanilla JavaScript, Bootstrap 5 and Font Awesome. No React, TSX or other frontend framework is used.

## Pages
Admin login, marketplace overview, customer management, vendor management and approval, category management, product management and approval, orders, payments, commissions, coupons/offers, banners, returns/refunds, reports, notifications and settings. Add category, coupon, banner and notification forms are individual HTML pages as well.

All displayed records and metrics are representative Indian-market sample data (INR, IST, GST context, Indian locations and DD MMM YYYY dates). Forms show backend endpoint placeholders. No backend, authentication, database persistence, financial calculation or live operation is included; implement those on the server before production use.

Open `index.html` to preview the dashboard. `login.html` is the separate sign-in UI. Bootstrap and Font Awesome use CDN links; an internet connection is needed for those libraries.
